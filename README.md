# Webflix

## Overview
Webflix is an interactive and responsive web application built using modern web technologies. It provides a seamless user experience for browsing and interacting with movie-related content.

## Features
- **React.js & Redux:** Utilized for building dynamic and efficient UI components.
- **Tailwind CSS:** Used for styling to ensure a modern and responsive design.
- **Firebase:** Implemented for user authentication and deployment.
- **React Router:** Used for smooth navigation between pages.
- **Reusable Components:** Optimized UI by structuring components for better maintainability.
- **State Management:** Managed global state using Redux reducers and actions.
- **Translation Support:** Enabled localization by integrating Redux for handling multiple languages.

## Technologies Used
- **Frontend:** React.js, Redux, Tailwind CSS, JSX
- **Authentication & Deployment:** Firebase
- **Routing:** React Router
- **Version Control:** Git & GitHub

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/AdityaGodambe-555/webflix.git
   ```
2. Navigate to the project directory:
   ```sh
   cd webflix
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm start
   ```
